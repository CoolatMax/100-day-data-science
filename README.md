## 🛠️ Repository Architecture

- `notebooks/`: Daily exploratory notebooks organized by curriculum milestone.
- `src/`: Reusable Python modules for data loading, transformation, and visualization.
- `data/`: Local data directory (`raw/` for input benchmarks, `processed/` for pipeline outputs).

## ⚙️ Environment Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/CoolatMax/100-days-of-data-science.git](https://github.com/CoolatMax/100-days-of-data-science.git)
   cd 100-days-of-data-science
   ```

2. **Set up virtual environment & install dependencies:**
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```
