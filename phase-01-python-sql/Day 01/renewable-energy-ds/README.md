# Renewable Energy Data Science

## Objective
The primary objective is to create a clean-energy project repository with README, virtual environment instructions and a script that loads a small solar-generation CSV and prints summary statistics.

## Dataset
The Data set is taken from Renewable.ninja.com and further filtered by country (Germany)

## Project Structure 
Follow the current repo for the structure

## Environment Setup
- for local
1. Fork the repo and click on Code
2. Toggle on Local
3. Based on your preference, select between (HTTPS, SSH, GITHUB CLI)
4. Copy the link below
5. Clone the Repo
6. Create a branch and work

- for github codespace
1. Fork the repo and click on Code
2. Toogle on codespace
3. Open the Codespace 
4. Create a Branch and work
