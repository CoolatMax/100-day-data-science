# Renewable Energy Data Science

## Objective
Create an aerospace telemetry repository with README, environment setup and a script that loads engine sensor CSV data and prints row/column metadata.

## Dataset
The Data set is taken from NASA CMPASS 

## Project Structure 
Follow the current repo for the structure

## Environment Setup
- for local
1. Fork the repo and click on Code
2. Toggle on Local
3. Based on your preference, select between (HTTPS, SSH, GITHUB CLI)
4. Copy the link below
5. Clone the Repo
6. Create a branch and work

- for github codespace
1. Fork the repo and click on Code
2. Toogle on codespace
3. Open the Codespace 
4. Create a Branch and work
